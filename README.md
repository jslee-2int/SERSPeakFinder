## 프로그램 개요
이 프로그램은 라만 스펙트럼 데이터를 처리하고 분석하는 종합 도구입니다. 라만 분광법으로 얻은 데이터를 효율적으로 처리하고, 머신러닝 기술을 활용하여 피크를 자동으로 검출하며, 결과를 시각화하고 분석할 수 있습니다.

### 주요 특징
- 직관적인 그래픽 사용자 인터페이스(GUI)
- 딥러닝 기반 자동 피크 검출
- 실시간 데이터 시각화
- 배치 처리 지원
- 자동 보고서 생성

## 시스템 요구사항

### 하드웨어 요구사항
- CPU: 듀얼 코어 이상 권장
- RAM: 8GB 이상 권장
- 저장공간: 최소 1GB 이상의 여유 공간
- GPU: NVIDIA GPU 권장 (딥러닝 모델 학습 시)

### 소프트웨어 요구사항
- 운영체제: Windows 10 이상
- Python 3.8 이상
- 필수 라이브러리:
  - PyQt6: GUI 프레임워크
  - NumPy: 수치 연산
  - Pandas: 데이터 처리
  - PyTorch: 딥러닝 프레임워크
  - SciPy: 과학 계산
  - Matplotlib: 데이터 시각화

## 상세 사용 설명서

### 1. 데이터 변환 탭
#### 기능 개요
- 원본 라만 스펙트럼 데이터를 분석 가능한 형태로 변환
- 좌표 기반 데이터를 개별 스펙트럼 파일로 분리

#### 상세 사용법
1. 데이터 파일 선택
   - 'Browse' 버튼 클릭
   - 변환할 원본 데이터 파일 선택 (.txt 또는 .csv 형식)
   - 지원 형식: 탭으로 구분된 텍스트 파일

2. 출력 설정
   - 출력 폴더 선택
   - 변환된 파일은 자동으로 (x_y).csv 형식으로 저장

3. 변환 실행
   - 'Process' 버튼 클릭
   - 변환 진행 상황 확인
   - 완료 후 파일 목록 자동 업데이트

4. 결과 확인
   - 좌측 리스트에서 변환된 파일 선택
   - 우측 그래프 영역에서 스펙트럼 확인
   - 마우스 드래그로 그래프 확대/축소 가능

### 2. 데이터 분류 탭
#### 기능 개요
- 스펙트럼 데이터의 피크 유무를 수동으로 분류
- 학습 데이터셋 생성을 위한 레이블링 작업

#### 상세 사용법
1. 데이터 폴더 설정
   - 'Browse' 버튼으로 CSV 파일이 있는 폴더 선택
   - 트리뷰에 파일 목록 자동 로드

2. 피크 검출 범위 설정
   - Center Wavelength: 관심 영역의 중심 파장
   - Range: 중심 파장으로부터의 검색 범위
   - 입력 후 그래프에 수직선으로 표시

3. 데이터 분류 작업
   - 파일 선택 시 스펙트럼 자동 표시
   - 키보드 단축키로 빠른 분류:
     - 'A': 피크 있음 (1)
     - 'D': 피크 없음 (0)
   - 화살표 키로 이전/다음 파일 이동

4. 분류 결과 저장
   - 자동으로 .dat 파일로 저장
   - 'Run Classifier' 버튼으로 전체 결과 CSV 저장

### 3. 모델 학습 탭
#### 기능 개요
- CNN 모델을 사용한 피크 검출기 학습
- 실시간 학습 진행 상황 모니터링

#### 상세 사용법
1. 데이터 설정
   - Training Data Folder: 학습 데이터 폴더 선택
   - Info File: 레이블 정보가 있는 CSV 파일 선택
   - Model Save Path: 학습된 모델 저장 경로 지정

2. 하이퍼파라미터 설정
   - Epochs: 학습 반복 횟수 (기본값: 300)
   - Batch Size: 배치 크기 (기본값: 64)
   - Test Size: 테스트 데이터 비율 (기본값: 0.2)
   - Random State: 랜덤 시드 값
   - Validation Split: 검증 데이터 비율 (기본값: 0.2)

3. 학습 실행
   - 'Start Training' 버튼 클릭
   - 진행 상황 실시간 표시:
     - 현재 Epoch
     - Train/Test Loss
     - Train/Test Accuracy
   - 그래프 실시간 업데이트:
     - Loss 그래프
     - Accuracy 그래프

4. 결과 확인
   - 최고 성능 모델 자동 저장
   - 학습 로그 확인 가능

### 4. 피크 검출 탭
#### 기능 개요
- 학습된 모델을 사용한 자동 피크 검출
- 배치 처리 지원

#### 상세 사용법
1. 모델 설정
   - Model File: 학습된 모델 파일 선택
   - Target Folder: 검사할 데이터 폴더 선택
   - Batch Size: 처리 배치 크기 설정

2. 검출 실행
   - 'Start Detection' 버튼 클릭
   - 진행률 표시줄로 진행 상황 확인
   - 결과 테이블 자동 업데이트

3. 결과 확인
   - 파일명
   - 피크 검출 결과 (0 또는 1)
   - 신뢰도 점수
   - ↑↓ 키로 결과 탐색하며 그래프 확인

4. 결과 저장
   - 'Save to CSV' 버튼으로 결과 파일 저장
   - 파일명, 검출 결과, 신뢰도 점수 포함

### 5. 결과 비교 탭
#### 기능 개요
- CNN 모델의 검출 결과와 수동 분류 결과 비교
- 정확도 분석 및 통계 정보 제공

#### 상세 사용법
1. 비교 파일 선택
   - CNN Model Result: 모델 검출 결과 파일
   - Manual Classification: 수동 분류 결과 파일

2. 비교 실행
   - 'Match Result' 버튼 클릭
   - 비교 결과 자동 계산

3. 결과 분석
   - 일치/불일치 건수
   - 전체 정확도
   - 오분류 상세 분석:
     - 피크 있음 오분류 수
     - 피크 없음 오분류 수

4. 결과 저장
   - 'Save Report' 버튼으로 상세 보고서 저장
   - 파일별 비교 결과 포함

### 6. 적분 분석 탭
#### 기능 개요
- 스펙트럼 데이터의 정량적 분석
- Savitzky-Golay 필터링 및 적분 계산

#### 상세 사용법
1. 데이터 설정
   - Report File: 분석할 보고서 파일 선택
   - Data Folder: 스펙트럼 데이터 폴더 선택

2. 분석 파라미터 설정
   - Window Length: SG 필터 윈도우 크기
   - Polyorder: 다항식 차수
   - Center Wavelength: 분석 중심 파장
   - Range Value: 분석 범위

3. 분석 실행
   - 'Process' 버튼 클릭
   - 결과 테이블 자동 생성:
     - 파일명
     - 피크 유무
     - 적분값

4. 결과 시각화
   - 원본 데이터
   - 필터링된 데이터
   - 적분 영역 표시
   - ↑↓ 키로 결과 탐색

2. 메모리 사용량 관리
   - 대용량 파일 처리 시 배치 처리 활용

   - 불필요한 데이터 즉시 해제

## 자주 묻는 질문

### 데이터 관련
Q: 지원되는 입력 파일 형식은 무엇인가요?
A: 탭으로 구분된 텍스트 파일(.txt) 또는 CSV 파일(.csv)을 지원합니다.

Q: 데이터 변환 시 파일명 형식을 변경할 수 있나요?
A: 현재는 (x_y).csv 형식으로 고정되어 있습니다.

### 모델 학습 관련
Q: 최적의 하이퍼파라미터는 무엇인가요?
A: 데이터셋 특성에 따라 다르지만, 일반적으로 다음 값을 권장합니다:
- Epochs: 300
- Batch Size: 64
- Test Size: 0.2
- Validation Split: 0.2

Q: 학습된 모델을 다른 데이터셋에 사용할 수 있나요?
A: 가능하지만, 새로운 데이터셋의 특성이 학습 데이터와 유사해야 합니다.

### 결과 분석 관련
Q: 피크 검출 신뢰도 점수는 어떻게 해석하나요?
A: 0~1 사이의 값으로, 1에 가까울수록 피크가 존재할 확률이 높습니다.

Q: 적분 분석 결과의 단위는 무엇인가요?
A: 상대적인 단위로, 스펙트럼의 세기와 파장 범위의 곱입니다.
